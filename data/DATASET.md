# Dataset: Synthetic Handwritten Indian Bills

## Overview

This directory contains **synthetic** bill images generated with Python's Pillow library
to simulate handwritten Indian receipts. They serve as working test data for the
evaluation pipeline.

## Limitations of Synthetic Bills

- **Not real handwriting**: These images use system fonts with slight randomization,
  not actual handwriting. Real bills will have:
  - Inconsistent letter shapes
  - Smudges, creases, uneven lighting
  - Overlapping text, varied ink density
  - Non-standard layouts

- **Controlled content**: Every field in the ground truth is exactly what appears on
  the image, with no genuine ambiguity. Real bills often have:
  - Partially illegible text
  - Ambiguous dates (is "1/2/24" January 2 or February 1?)
  - Missing or truncated information

## Replacing with Real Bills

To evaluate with real handwritten bills:

1. Place bill images (PNG, JPG) in `data/bills/`
2. Update `data/ground_truth.json` — one entry per image with fields:
   - `image_file`: filename in `data/bills/`
   - `vendor_name`: shop/vendor name as written
   - `invoice_number`: bill number, or `null` if not present
   - `date`: ISO date (YYYY-MM-DD) if parseable, or `null`
   - `date_raw`: date exactly as written on the bill
   - `date_ambiguous`: `true` if date is genuinely ambiguous
   - `amount`: total amount (float)
   - `currency`: "INR" unless stated otherwise
   - `gst_details`: free text with GSTIN, tax amounts, or `null`
3. Run `python src/run_eval.py` to re-evaluate

## Generation Script

Bills were generated by `src/generate_bills.py`. Run it to regenerate:

```bash
python src/generate_bills.py
```
